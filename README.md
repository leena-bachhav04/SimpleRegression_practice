# Simple Linear Regression Practice

This project is a beginner-level practice of **Simple Linear Regression** using Python and Scikit-learn.

## Objective

The goal of this practice is to understand how Linear Regression can be used to predict a student's **CGPA based on IQ**.

## Dataset

The dataset contains two main columns:

* **IQ** – Input feature
* **CGPA** – Target variable

## Concepts Practiced

* Understanding Linear Regression
* Independent and dependent variables
* Train-test split
* Model training
* Making predictions
* Regression line visualization
* Model evaluation
* Mean Squared Error (MSE)
* R² Score

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Basic Workflow

1. Load the dataset
2. Explore the data
3. Select IQ as the input feature
4. Select CGPA as the target
5. Split the data into training and testing sets
6. Train the Linear Regression model
7. Make predictions
8. Visualize actual vs predicted values
9. Evaluate the model using MSE and R² Score

## Model

The Linear Regression equation is:

`CGPA = b0 + b1 × IQ`

Where:

* `b0` = Intercept
* `b1` = Regression coefficient
* `IQ` = Input feature
* `CGPA` = Predicted target

## Evaluation Metrics

### Mean Squared Error (MSE)

MSE measures the average squared difference between actual and predicted CGPA values.

### R² Score

R² indicates how well the model explains the variation in CGPA.

## Learning Outcome

Through this practice, I learned the basic mathematics and implementation of **Simple Linear Regression** and understood how a machine-learning model learns the relationship between an input feature and a continuous target variable.
